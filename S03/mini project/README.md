# User Profile System

This is a simple PHP-based user profile system for Session 03 practice.

## Setup
- Place in XAMPP/htdocs.
- Access via http://localhost/public/login.php.
- Users stored in storage/users.json.

## Features
- Registration with validation.
- Login with session.
- Profile edit with avatar upload.
- Logout.

Run acceptance tests manually as per workbook.
